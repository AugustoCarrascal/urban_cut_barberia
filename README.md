# 💈 Urban Cut Barber — Landing Page

Landing page moderna y de alto rendimiento diseñada para **Urban Cut Barber**, una barbería de estilo industrial y oficio clásico. Ofrece a los clientes una experiencia fluida para consultar servicios, lista de precios, galería de trabajos y agendar turnos directamente por WhatsApp.

## 🚀 Características
- **Reserva de turnos directa:** Integración con botón directo a WhatsApp.
- **Sección de Servicios y Precios:** Menú claro de cortes, perfilado de barba, combos VIP y coloración.
- **Diseño Responsive & Industrial:** Interfaz adaptable a celulares y computadoras con estética urbana.
- **Galería de Trabajos & Reseñas:** Muestra de cortes finalizados y opiniones reales de clientes.
- **Ubicación y Horarios:** Información relevante de contacto y horarios de atención comercial.

## 🛠️ Tecnologías utilizadas
- **HTML5:** Estructuración semántica.
- **CSS3 / Tailwind CSS:** Estilos visuales y diseño responsive.
- **GitHub Pages:** Despliegue e hosting continuo.
